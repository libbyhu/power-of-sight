## 與第七版的差異

| 第七版 | v8 |
|---|---|
| Supabase（Postgres + Auth + RLS） | Spring Boot + JPA + 自己的會員系統 |
| Magic link 登入 | Email + 密碼 |
| 書庫／電影／電視劇／動漫四個分頁，書再分中英日文、工具書 | 一間「我的書房」，種類與狀態都是篩選 |
| 願望清單是獨立頁 | 書房裡「想讀／想看」的篩選（網址 `/room?status=WANT`） |
| 狀態必填 | 狀態可以不填 |
| 四張 detail 表（作者、導演…） | 一個 `creator` 欄位，依種類換標籤 |
| 價格追蹤（手動） | 暫時移除 |

第七版存在 Supabase 的資料沒有搬過來（作者決定捨棄）。
