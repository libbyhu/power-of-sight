# 05 上線路線圖

更新：2026-11-19

## 上線對象與順序

| 階段 | 使用者 | 開放條件 |
|---|---|---|
| 第 1 段 | 作者本人 | 部署完成、核心流程每天可用 |
| 第 2 段 | 受邀朋友（約 5–10 人） | 帳號安全與個資處理完成（見第 2 段清單） |
| 第 3 段 | 公開註冊 | 第 2 段穩定運作，並完成公開服務所需的條款、防濫用與維運項目 |

每一段結束都要有可實際使用的成果；未完成的功能不阻擋上一段已可用的部分。

## 平台選擇：PWA

第一版以 PWA（可安裝到手機主畫面的網頁應用程式）提供，不製作原生 App。

- 同一份程式碼支援手機與電腦。
- 不需要應用程式商店審核與上架費用。
- `frontend/public/manifest.json` 已存在，可在此基礎上補齊。

原生 App 待使用者規模確立後再評估。

## 第 0 段：整理基礎

目標：程式碼有版本紀錄、有一致的規範，每次修改都會自動檢查。

- [ ] 建立 Git 版本庫並推上 GitHub
- [ ] 撰寫 `docs/00-開發規範.md`：命名、分支、commit 訊息、API 與錯誤代碼格式、測試原則
- [ ] 前端：ESLint + Prettier
- [ ] 後端：程式碼格式化工具（Spotless）
- [ ] GitHub Actions：推送時自動執行後端測試、前端型別檢查與建置
- [ ] 以 `docker-compose.yml` 實際連線 PostgreSQL，跑完整流程並記錄結果

## 第 1 段：作者本人每天可用

目標：放在雲端、手機也能順手使用。

- [ ] 部署：前端（Vercel）；後端與 PostgreSQL（Render、Railway 或 Fly.io 擇一，依當時方案與費用決定）
- [ ] 全站 HTTPS，`COOKIE_SECURE=true`，正式環境使用獨立的 `JWT_SECRET`
- [ ] 作品搜尋：Google Books（書）、TMDB（電影、影集、動畫），選取後自動帶入名稱、作者與封面
- [ ] 手機版面檢查與調整
- [ ] PWA：圖示、啟動畫面、可加入主畫面
- [ ] 試用期間的問題紀錄（GitHub Issues）

## 第 2 段：開放給受邀朋友

目標：他人託付資料時，帳號與資料都受到妥善保護。以下項目全部完成前不開放。

**帳號安全**
- [ ] 忘記密碼：寄送一次性重設連結（需接入寄信服務）
- [ ] 登入嘗試次數限制
- [ ] 修改密碼

**個資與資料**
- [ ] 刪除帳號（連同書房與所有收藏）
- [ ] 匯出自己的資料（JSON 或 CSV）
- [ ] 隱私權政策頁面（說明收集哪些資料、用途、保存與刪除方式）

**維運**
- [ ] 資料庫每日自動備份，並實際演練一次還原
- [ ] 錯誤通知（例如 Sentry）
- [ ] 意見回饋入口

**邀請方式**
- [ ] 註冊需要邀請碼（避免在此階段開放任何人註冊）

## 第 3 段：公開註冊

- [ ] 移除邀請碼限制，加入註冊時的 Email 驗證
- [ ] 服務條款
- [ ] 防濫用：註冊與 API 的頻率限制
- [ ] 自有網域名稱
- [ ] 公開書房與訪客參觀（只顯示使用者設為公開的內容）
- [ ] 監控回應速度與資料庫用量，評估付費方案

## 體驗與美術（可穿插進行，不阻擋上線）

- 以開場動畫的道具（書架、門、旅人、CRT）延伸書房頁的裝飾
- 書房內手動排序（`display_order` 欄位已預留）
